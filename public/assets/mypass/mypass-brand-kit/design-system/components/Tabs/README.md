# Tabs

Onglets et contrôle segmenté : les onglets changent de contenu, le contrôle segmenté change la vue d'un même contenu.

- Onglet actif : texte `mp-text-primary` 600 + indicateur 3px `mp-selected-indicator`. Compteur facultatif en pastille `mp-bg-subtle`.
- Contrôle segmenté : 2 à 5 options courtes (7 j, 30 j). Option active sur `mp-bg-surface` avec `mp-shadow-1`.
- Rôles ARIA `tablist` / `tab` / `aria-selected`, flèches clavier entre onglets.
