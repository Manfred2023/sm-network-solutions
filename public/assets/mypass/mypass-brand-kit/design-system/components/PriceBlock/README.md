# PriceBlock

Bloc de prix : catégories de billets avec quantité, puis récapitulatif et CTA unique.

- Catégorie sélectionnée : bordure 2px `mp-border-strong`. Épuisée : fond `mp-bg-subtle` + badge « Épuisé ».
- Prix en `mp-price` (600, tabulaire). Frais toujours affichés avant le paiement, jamais ajoutés à la dernière étape.
- Stepper 40px ; le bouton « − » est désactivé à 0.
- Sur mobile, le récapitulatif devient une barre fixe en bas avec total et CTA.
