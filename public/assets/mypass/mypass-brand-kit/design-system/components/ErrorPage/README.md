# ErrorPage

Pages d'erreur : expliquer, rassurer sur l'argent et les billets, proposer une sortie.

- 404 : « 4 [symbole] 4 » en display, message « Cette porte ne mène nulle part ».
- 500 / panne : préciser qu'aucun paiement n'a été débité et que les billets restent valides hors connexion. Afficher une référence d'incident en `mp-code`.
- Toujours deux actions : réessayer ou revenir, et un lien vers l'état du service.
