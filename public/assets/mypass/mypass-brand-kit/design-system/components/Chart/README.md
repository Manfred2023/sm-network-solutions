# Chart

Graphiques : une série en Nuit (Craie en sombre), la période courante en Volt cerclé de Nuit.

- Une série = une couleur. Pour comparer des catégories, préférer des barres horizontales triées avec étiquettes directes.
- Pas de double axe, pas de camembert au-delà de 3 parts, pas de 3D.
- Grille `mp-border-subtle`, axes `mp-text-secondary` 11px tabulaires. Barres arrondies 2px côté données.
- Chaque graphique a un titre, un chiffre clé au-dessus et une phrase de lecture en dessous ; info-bulle au survol, tableau équivalent disponible.
