# Checkout

Page de paiement : trois étapes, minuteur de réservation, moyens de paiement locaux en premier.

- Le minuteur (`warning`) apparaît dès que des places sont bloquées ; à 0, une modale propose de relancer la réservation.
- Ordre des moyens de paiement selon le pays de l'événement : Mobile Money d'abord en Afrique centrale et de l'Ouest, carte d'abord en Europe et Amérique du Nord.
- Le total reste visible en permanence (aside desktop, barre fixe mobile). Le CTA reprend le montant exact.
- Une seule colonne de champs, pas de champ superflu : nom, e-mail, téléphone si Mobile Money.
