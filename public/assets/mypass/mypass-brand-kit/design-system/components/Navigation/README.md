# Navigation

Navigation : barre supérieure pour le site public, sidebar pour l'espace organisateur, barre d'onglets en bas sur mobile.

- Élément courant : `aria-current="page"`, fond `mp-selected-bg`, graisse 600. Sur la barre mobile, l'icône courante est posée dans une pilule Volt.
- Barre mobile : 4 entrées maximum (Découvrir, Rechercher, Mes billets, Profil), libellés toujours visibles.
- Sidebar : largeur `mp-size-sidebar` (264px), groupes titrés en overline. Repliée en icônes sous `mp-bp-lg`.
- Le logo de la barre utilise le lockup horizontal à 24px de haut (compact sous 120px de large).
