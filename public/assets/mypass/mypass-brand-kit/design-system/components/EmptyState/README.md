# EmptyState

État vide : une arche dessinée, un titre qui nomme ce qui manque, une phrase utile, une action.

- Illustration au trait 3px `mp-text-primary`, porte remplie `mp-bg-brand`. Toujours la même famille de formes, jamais d'illustration de personnage.
- Titre en Bricolage 22px. Texte `mp-text-secondary`, 36 caractères par ligne max.
- Distinguer « rien encore » (action pour commencer) de « aucun résultat » (action pour élargir les filtres).
