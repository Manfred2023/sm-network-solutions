# Modal

Modale : interrompt pour une décision, jamais pour une information.

- Desktop : 440px max, rayon `mp-radius-xl`, `mp-shadow-3`, voile `rgba(11,12,16,.56)`. Mobile : bottom sheet `.mp-sheet`.
- Titre en question (« Annuler la commande #A-20931 ? »), texte qui chiffre les conséquences, deux actions : la sortie sûre à gauche, l'action engagée à droite avec son verbe exact.
- Focus piégé, Échap ferme, retour du focus sur le déclencheur.
