# Logos

Logo MyPass : symbole « La Porte » + logotype vectorisé (Bricolage Grotesque 800, largeur 90). Fichiers SVG vectoriels, sans police.

- `*-nuit` : tout en Nuit #111218, pour fonds clairs (Craie, blanc).
- `*-inverse` : symbole Volt #D4F03C + logotype Craie #F7F6F2, pour fonds Nuit ou photos sombres.
- `*-sur-volt` : tout en Nuit, pour aplats Volt.
- `*-mono-noir` / `*-mono-blanc` : impression une couleur.
- `horizontal` = usage courant ; `principal` = version empilée ; `compact` = 72–120px de large.
- `mypass-symbole-*` : symbole seul, encre indiquée par le nom (nuit #111218, volt #D4F03C, craie #F7F6F2, noir, blanc).
- `favicon.svg` : symbole Volt agrandi dans une tuile Nuit rayon 7/32.

Zone de protection = M (épaisseur du fût, 30 % de la hauteur du symbole). Minimums : horizontal 96px, empilé 64px, symbole 16px.
